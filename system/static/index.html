当前程序版本：V1.1。版本说明随程序发布，按新到旧保留历次更新；不代表已有任务、历史报告或设备数据已自动迁移。

V1.1 · 2026-10-25

  • 新增“版本说明”入口，可查看当前及历史版本的更新内容，不影响未保存的任务。
  • 报告对象拆分为水表、流量计（气体）、流量计（液体）、燃气表四类；旧“流量计”兼容归入液体类，资料按类型隔离。
  • 新增气体涡街、超声流量计的观察记录、项目一览表和试验结果素材；兼容液体素材目录名称。
  • 气体流量计支持 Excel 原始记录、误差及重复性匹配、耐压工作压力回填、初始及复测大气压力识别，以及配套原始记录打印页。
  • 气体流量计附件2沿用燃气表照片版式，两类照片数据保持隔离；配套原始记录不新增照片附件。
  • 拆分结果表的序号、项目名称、技术要求按各列相邻相同文字合并，保留首格格式，不合并样机或实测结果。
  • 统一三类试验拆分页眉的标题居中、编号右对齐及长编号避让；修复独立结果的设备、环境和人员页底异常分页。
  • 试验结果的标题、开始及结束时间、数据记录，以及判定要求、结论、异常记录段落统一为1.5倍行距、段前段后0；同步规范源素材。
  • 历史任务的素材引用迁移须逐行核对样机和技术要求，保留实测值、人工修改、来源及历史记录，不按名称猜配。
  • 修复 Windows 云端备份及恢复校验未及时关闭 SQLite 连接造成的临时文件占用问题。

已有导出不会自动改变。使用新的试验拆分规则前，请重新“保存检查”并导出；最终文档仍需人工审版，真实 Word 分页能力取决于运行环境。

V1.0 · 既有线上版本

  • 支持水表、流量计、燃气表的任务管理、资料上传、样机对应、结果核对及 Word 报告生成。
  • 提供普通及试验报告拆分、设备库、备份与校验、历史报告下载。
  • 云端支持素材缓存及批量预加载、非阻塞素材和照片加载、首页合并加载与打开任务合并核对。
  • 云端支持照片标准及高清优化、按需缩略图和下载校验；保留已有照片及历史报告。
